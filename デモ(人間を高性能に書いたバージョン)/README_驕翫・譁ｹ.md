# ASHEN FRONTIER — 冒険者の辺境 / v1

## 目的
前回「FPS・人物NPC 改修版 v3」が動いたというフィードバックを元に、同じ **ブラウザ + Three.js + ポインターロック** の形式で、遊べる冒険者ゲームを新規制作したものです。Blender動作検証ツールとは異なり、`run_windows.bat` でゲームとして起動します。

## 起動方法（Windows）
1. ZIPを任意のフォルダーに展開します（ZIP内部から直接実行しないでください）。
2. `run_windows.bat` をダブルクリックします（Python 3が必要です）。
3. Edge / Chromeで `http://localhost:8000` を開きます。
4. 「冒険を始める」を押します。
5. ゲーム画面にマウスカーソルが固定され、マウスで視点を変えられます。

`http://localhost:8000` が別アプリで使用中の場合は、`run_windows.bat` 内のポート番号を両方とも8001などに変更してください。

Three.js本体・GLTFLoader・SkeletonUtilsとサンプル人物モデルはオンラインで読み込むため、**初回からインターネット接続が必要**です。モデルの読み込みに失敗しても、ゲームはFPS視点で開始できます（ただしThree.jsライブラリ自体の読み込みに失敗するとプレイできません）。

## メインクエスト
1. 村のギルド長アーリンと話す。
2. 古の森で魔獣3体を討伐。
3. ギルドに戻り討伐報告。
4. 忘却の遺跡に向かい、守護者を倒して遺物を回収。
5. ギルドへ届けて初章クリア。

## 実装範囲
- 村、森、遺跡、道、木、岩、草、水、建物、照明、霧
- マウス視点、WASD移動、FPSモード、人物GLBがある場合は三人称モード
- 近接剣攻撃、敵の巡回・追跡・攻撃、HP・スタミナ、回避、回復
- NPC会話、クエスト、簡易ショップ、戦利品、薬草、宝箱
- レベル、XP、金貨、ミニマップ、セーブ（localStorage）
- 導入したリグ付きGLBのアニメーション再生（Idle / Walk / Run / Attack など）

## 重要：人間の品質
**高品質な人体メッシュはこのZIPに同梱していません。** 権利確認ができていないCGTrader / Sketchfab / Meshy のモデルを勝手に再配布することはしません。

読み込み優先順位：
1. `assets/human.glb`（ユーザーが取得したリグ・スキニング済み人物GLB）
2. Three.js公式例の `Soldier.glb`（オンラインのデモ用、フォトリアルではありません）

いずれも読めなければゲームをFPS視点で遊べます。人物NPCには抽象的なギルド目印を表示し、人間モデルがあるかのようには装いません。

CGTraderで入手した `.blend/.fbx` はBlenderで **glTF Binary (.glb)** に書き出し、必ず `Armature` と `SkinnedMesh`、UV・PBRマテリアル、可能ならIdle/Walk/Runアニメーションを含めてください。人物の顔・肩・関節の品質はソースGLBに依存します。骨格構造が違う場合はアニメーションのリターゲティングが必要です。

## 画質と制約
このゲームはプレイ可能なアドベンチャープロトタイプです。森・建物・魔獣等はプロシージャルであり、AAA級フォトリアルの完成品ではありません。人物モデルのみ球体を組み上げず、アセットベースで描画します。敵のダメージ・当たり判定は簡易的な距離／向き判定です。衝突判定は建物の矩形による簡易処理です。

## 技術
