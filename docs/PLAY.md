LIVING WORLD — エルム村の朝 / 開発ビルド 0.3.0

Windows: ZIPを展開して LivingWorld.exe を起動。
Linux: ZIPを展開して LivingWorld.x86_64 に実行権限を付けて起動。
この版はSteam向けに制作中のローカル版です。Steamアカウントは不要です。

操作
WASD：カメラ方向を基準に移動 / マウス：三人称視点 / Shift：走る / E：近くの対象を調べる
左クリック：攻撃 / H：傷薬 / I：持ち物 / J：手帳 / Esc：メニュー / F5：保存
ゲームパッド：左スティック移動、右スティック視点、A調べる、B戻る、Y荷物、X傷薬、RT攻撃。
UIはTab・方向キーでフォーカス移動、Enter/Aで決定できます。設定画面でBGM音量を変更できます。
建物の近くではカメラが寄ります。村の荷箱は歩いて押せます。北の遺跡ではBGMが切り替わります。

最初の遊び方（約10～20分）
1. 村の北側にある「村の依頼」の掲示板をEで開き、鉄鉱石の依頼を受けます。
2. 西の「鉄鉱石」へ歩き、Eで3個採集。採集には短い待ち時間があります。
3. 掲示板へ戻り、納品して報酬を受け取ります。
4. 南西の訓練場で3回訓練して剣士に転職できます。
5. 鉄鉱石3個と木材1個を集めて鍛冶場で剣を製造します。
6. 薬草2個と木材1個から東の工房で傷薬も作れます。
7. 銀行へ大事な品や銅貨を預け、北門の先の遺跡へ向かいます。
8. 守り手の攻撃を距離で避けながら戦います。Hで傷薬を使えます。
9. 死亡時は携行品と携行金の25%を失い、レベルが2低下（最低1）。銀行保管は安全です。
10. 遺品は遺跡の回収箱へ移り、剣は守り手が拾うことがあります。倒して同じ品を回収できます。

木材の修復依頼を完了すると北門と木材の価格が変化します。
NPCは時間帯に合わせて仕事・食事・休息を行い、在庫に応じて素材と製品を供給します。
メニュー中も村の時間は進みます。タイトル表示中とアプリ終了中は進みません。
製造中に持ち物がいっぱいになった場合、完成品は工房で受取待ちになります。

保存
操作確定時と30秒ごとに自動保存。F5またはメニューでも保存できます。
通常の製品版実行時：Godotのユーザーデータ領域（WindowsではAppData/Roaming/Godot/app_userdata/LIVING WORLD）。
Linux開発ラッパー使用時：リポジトリの .local/data/godot/app_userdata/LIVING WORLD。
world.json と world.json.bak は1組で保管してください。ゲーム内の新規開始は旧セーブを別名で残します。

現段階の範囲
1村・30NPC・3素材・2レシピ・2基礎職・市場・貸金庫・2依頼・近接戦闘・死亡・遺品回収。
Blenderで制作した人物4種類、家屋・露店・井戸など9種類の村用モデル、手に追従する剣、待機・歩行・走行・攻撃モーション、村・遺跡のBGMと効果音を収録しています。人物・建物のアートには製品品質までの追加制作が必要です。オンライン、Steamworks、車両、遠距離物流、司法、魔法は今後の工程です。
